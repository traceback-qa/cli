# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in the Traceback CLI, please do not disclose it publicly via GitHub issues.

Instead, please send an email to [security@traceback.dev](mailto:security@traceback.dev) or submit a private security advisory through the GitHub repository.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept code.
- Any suggested mitigations if available.

We will acknowledge receipt within 48 hours and work with you on a timely resolution and disclosure.
